# RAOTA 다국어

한국어(`ko`), 영어(`en`), 중국어 간체(`zh`), 일본어(`ja`)를 지원합니다. 기기/앱의 선호 언어 목록에서 지원하는 첫 언어를 선택하며, 없으면 한국어를 사용합니다. 중국어 지역·문자 변형은 현재 모두 간체로 표시합니다.

- 모바일: `apps/mobile/src/i18n.ts`가 `expo-localization`에서 앱 언어를 읽습니다. 화면은 `useLocale()`로 구독하며 언어 변경과 포그라운드 복귀에 갱신합니다. 화면을 재마운트하지 않습니다.
- 웹: `src/main.tsx`가 `navigator.languages`를 읽고 `languagechange`를 구독합니다. HTML 언어도 갱신합니다.
- 시스템의 앱별 언어 선택 및 iOS 권한 안내: `apps/mobile/app.json`의 `expo-localization` 플러그인과 `apps/mobile/locales/*.json`에 선언했습니다. 네이티브 설정 변경은 새 앱 빌드가 필요합니다.

## 문구 추가

`t("기록 {count}개", { count })`처럼 한국어 원문을 키로 사용합니다. `core.ts`, `mobile-flows.ts`, `mobile-surfaces.ts`, `web.ts`의 값은 `[영어, 중국어 간체, 일본어]` 순서입니다. 모든 번역은 원문의 `{변수}`를 유지해야 합니다. 문장을 여러 조각으로 번역하지 말고 변수로 연결합니다. 빠진 키는 한국어 원문으로 표시됩니다.

`t()`는 렌더링 시점에 호출합니다. 번역된 값을 메모하면 `useLocale()`의 반환값을 의존성에 넣습니다. 상태에는 원문 키와 변수를 보관하고, 모듈 전역에서 번역 결과를 상수로 저장하지 않습니다. 날짜/숫자 표시는 `formatDate`, `formatNumber`, 외부 위젯의 locale은 `getIntlLocale()`을 사용합니다. 금액은 실제 통화(KRW)를 유지합니다.

## API와 저장 데이터

API 요청에는 현재 언어를 `Accept-Language`로 전달합니다. 서버가 지원할 때만 응답 언어가 달라집니다. 이 코드는 API 응답을 자동 번역하거나 외부 번역 API를 호출하지 않습니다. 사용자 글/리뷰/닉네임, 매장 고유명/주소/소개는 원문을 유지합니다. 약관·개인정보처리방침 본문은 한국어 원문을 유지하고 다른 언어에서는 원문 제공 안내를 표시합니다.

라멘 종류, 맛 태그, 재방문 선택지처럼 서버·저장소·필터에 쓰는 값은 기존 값을 그대로 사용하고 표시 라벨만 번역합니다. 닉네임 허용 문자는 서버 계약(한글·영문·숫자·밑줄)을 유지합니다.

## 검증

`apps/mobile/__tests__/i18n.test.tsx`가 언어 선택/폴백, 런타임 변경, 번역 변수 일치, 날짜·숫자, API 언어 헤더와 원문 응답 보존을 검사합니다. 모바일 기기에서는 앱별 언어 설정, 권한 안내, 작성 중인 폼 유지, 긴 영문과 일본어의 줄바꿈을 새 네이티브 빌드로 확인합니다.
