> **문서 버전**: v1.0.0  
> **최종 수정일**: 2026.09.02  
> **관련 모듈**: `ShopDetailScreen`, `ShopCard`, `RecordScreen`, `MapFilter`

## 1. 기획 배경 및 목적
라멘 매니아와 일반 방문객 모두에게 **"면 추가가 되는지"**, **"밥이 무료인지"**, **"와리습(육수)이 제공되는지"**는 매장 방문 만족도와 재방문 의사를 결정하는 핵심 정보입니다.

본 기획은 매장마다 제각각인 리필/제공 혜택을 4대 표준 카테고리로 체계화하여, 상세 페이지 노출 및 향후 검색/필터링에 활용할 수 있도록 정의합니다.

---

## 2. 4대 핵심 리필 & 제공 항목 정의

### ① 🍜 면 리필 (카에다마 / 替え玉)
- **정의**: 라멘 면을 다 먹은 후 국물에 추가하는 면 사리 혜택
- **제공 유형**:
  - `1회 무료 제공 ✓` (하카타 돈코츠 등 기본 1회 면 리필 제공 매장)
  - `반 그릇(반타마) 무료 ✓` (소량 리필 제공 매장)
  - `유료 추가 (+1,000원 ~ +2,000원)`
  - `제공 안 됨 (사이드 메뉴 확인)`

### ② 🍚 공깃밥 & 비빔밥 (오이메시 / 追い飯)
- **정의**: 남은 국물이나 마제소바/아부라소바 양념에 비벼 먹기 위한 밥
- **제공 유형**:
  - `요청 시 무료 제공 ✓` (공깃밥 1공기 또는 반공기 무료)
  - `무제한 셀프바 ✓` (밥솥에서 자유롭게 리필)
  - `오이메시(소량) 무료 ✓` (마제소바/비빔면 전용 2~3숟가락 분량)
  - `유료 공깃밥 (+1,000원)`

### ③ 🥣 육수 리필 (와리습 / 割りスープ & 온육수)
- **정의**: 츠케멘 소스가 진할 때 희석하거나, 국물 염도 조절을 위해 붓는 맑은 육수
- **제공 유형**:
  - `츠케멘 와리습 무료 ✓` (보온병 또는 요청 시 다시 육수 제공)
  - `무염 맑은 육수 제공 ✓` (짠맛 조절용 온육수 항시 요청 가능)
  - `해당 없음 (단일 국물)`

### ④ 🧄 반찬 & 양념 셀프바 (카라시타카나 / 마늘 / 다시마식초)
- **정의**: 매장에서 기본 또는 셀프로 마음껏 추가 가능한 토핑/반찬류
- **제공 유형**:
  - `갓절임(타카나) & 초생강 셀프바 ✓`
  - `통마늘(크러셔) & 다진마늘 무료 ✓`
  - `다시마식초 & 라유 구비 ✓`
  - `김치 & 깍두기 제공 ✓`

## 3. 데이터 모델 스펙 (TypeScript Interface)

```typescript
export interface ShopServicePerks {
  // 1. 면 리필
  noodleRefill?: string // 예: "1회 무료 제공 ✓", "반 그릇 무료 ✓", "유료 (+1,000원)"
  isNoodleFree?: boolean

  // 2. 밥 리필
  riceRefill?: string // 예: "요청 시 무료 제공 ✓", "오이메시 무료 ✓", "무제한 셀프바 ✓"
  isRiceFree?: boolean

  // 3. 육수 / 와리습
  soupRefill?: string // 예: "츠케멘 와리습 무료 ✓", "염도 조절 온육수 제공 ✓"
  isSoupRefillAvailable?: boolean

  // 4. 셀프바 / 양념
  condiments?: string[] // 예: ["갓절임(타카나)", "생마늘 크러셔", "다시마식초"]

  // 5. 검증 메타데이터
  lastVerifiedDate?: string // 예: "2026.09"
}
```

## 4. UI/UX 표현 가이드

1. **상세 페이지 정보 카드**:
   - 매장 상호명/주소 바로 아래에 불필요한 장식 타이틀 없이 2~3열의 콤팩트 카드 형태로 표시
   - 무료 혜택이 있는 항목은 RAOTA 시그니처 레드(`#E60000`) 또는 볼드 폰트로 하이라이트
2. **검색 & 탐색 필터 (추후 연동)**:
   - `[무료 밥 제공]`, `[면 리필 가능]`, `[와리습 제공]` 필터 태그 지원
3. **유저 집단지성 검증 (크라우드소싱)**:
   - "최근 정보가 변경되었나요? 수정 제안하기"를 통해 유저들이 혜택 변동 사항을 쉽게 제보할 수 있도록 유도

- 라멘 매니아에게 가장 가려운 정보를 1초 만에 제공하여 앱의 전문성 극대화
- 매장별 혜택에 따른 탐색 경험(예: "마제소바 먹고 밥 비벼 먹을 수 있는 곳") 증대
