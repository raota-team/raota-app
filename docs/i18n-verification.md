# RAOTA 다국어 적용과 검증

검증일: 2026-10-28. 작업 브랜치: `feat/app-localization`. 구현 커밋: `5425518`.

## 빌드 11 추가 검증

스페인어(`es`)를 추가해 다섯 언어를 지원합니다. `es-MX`, `es-AR`, `es-419` 등도 공통 스페인어 문구를 사용하며 날짜·숫자는 `es-ES`로 표시합니다. iOS/Android 앱별 언어 목록에 `es`를 선언하고 iOS 권한 안내를 추가했습니다.

최신 main의 빌드 10과 지난 식권 기능을 통합했습니다. 지난 식권의 날짜·목록·빈 상태·접근성 안내도 다섯 언어로 표시하고, 날짜 그룹 키는 언어에 영향받지 않는 서울 기준 날짜를 사용합니다. 식권의 서버 조건·가게명은 API 원문을 유지합니다.

- 전체 자동 검사: 32개 스위트, 400개 테스트 통과. 마지막 문구 보완 후 i18n 관련 34개 검사도 다시 통과했습니다.
- 모바일·공유·웹 TypeScript 및 웹 프로덕션 빌드 통과.
- iOS 앱 버전 `1.0.0`, 빌드 번호 `11`로 설정했습니다.
- 전용 iOS 시뮬레이터에서 스페인어 홈 화면과 날짜·탭 라벨이 오류 없이 표시됨을 확인했습니다.
- 웹 스페인어 홈·마이·가입 화면을 390px/1280px에서 확인했습니다. 가로 넘침과 자바스크립트 오류가 없으며, 닉네임 안내·라멘 종류 선택지도 현지화했습니다.

이전 네 언어의 네이티브/Android 검증은 아래 기록에 해당하며, 빌드 11의 스페인어 검증과 구분합니다.

## 적용 범위

- 한국어·영어·중국어 간체·일본어·스페인어를 지원합니다. 모바일은 OS의 앱 언어/선호 언어 목록, 웹은 브라우저 언어를 사용합니다. 지원하는 언어가 없으면 한국어로 표시합니다.
- 탭·버튼·폼·오류·접근성 안내·기록·취향 리포트·로컬 추천 설명·날짜와 숫자를 현지화합니다. 언어 변경 시 화면을 재마운트하지 않고 표시 문구를 갱신합니다.
- API 요청에 `Accept-Language`를 전달합니다. 응답을 자동 번역하지 않으며, 서버가 해당 언어를 지원해야 가게 소개나 서버 AI 설명도 바뀝니다. 리뷰·닉네임·가게 고유명·주소·약관 본문은 원문을 유지합니다.
- 저장/API/필터용 라멘 종류와 맛 태그 등은 기존 값을 유지하고 표시 라벨만 번역합니다. 금액은 실제 통화인 KRW를 유지합니다.
- 중국어 지역/문자 변형은 현재 모두 간체 번역으로 표시합니다.

## 검증 중 발견한 오류와 조치

초기 검증용 앱은 일반 빌드의 Info.plist에서 식별자만 바꾼 복사본이어서 `ERR_NOTIFICATIONS_KEYCHAIN_ACCESS`가 발생했습니다. iOS 시뮬레이터는 Xcode가 링크 시 생성하는 시뮬레이터용 entitlement도 필요합니다. 일반 iOS 권한을 사후 ad-hoc 서명에 직접 추가하면 실행 정책에 의해 앱 시작이 거절될 수도 있습니다.

검증용 `PRODUCT_BUNDLE_IDENTIFIER`를 Xcode 빌드 설정에 지정하고 정상 시뮬레이터 서명으로 다시 빌드했습니다. 이후 네 언어 화면에서 오류가 사라졌음을 확인했습니다. 오류를 무시하거나 앱 코드를 수정해 감추는 처리는 하지 않았습니다.

## 격리와 재실행

다국어 변경은 별도 워크트리와 브랜치에 보관했습니다. 원래 main의 자체 변경 패치를 제거하고 기존 iOS 생성 소스도 작업 전 백업으로 복원했습니다. 테스트 앱은 `com.raota.app.i18ncheck`로 분리했으며, iOS는 전용 `RAOTA-I18n-QA` 장치를 사용했습니다.

Metro는 이 워크트리의 앱·공유 소스를 사용하고, 외부로 연결된 pnpm 캐시가 있으면 그 제3자 의존성 저장소만 추가로 감시합니다. 기존 세션의 앱 소스나 8081 서버를 사용해 검증하지 않습니다. 새 워크트리의 Git LFS 이미지·글꼴은 `git lfs checkout`으로 복원해야 합니다.

네이티브 설정을 반영하려면 해당 워크트리에서 Expo prebuild 후 새 네이티브 빌드를 만듭니다. 검증용 iOS 앱 식별자를 바꿀 때는 Info.plist의 사후 수정 대신 Xcode 빌드 설정에서 지정하고 재빌드합니다.
