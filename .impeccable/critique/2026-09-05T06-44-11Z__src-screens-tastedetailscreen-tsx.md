# 마이페이지 라멘 리포트 로딩 개선 분석

대상: src/screens/TasteDetailScreen.tsx. 웹 프로토타입 기준. 2026-09-05.
독립 소스 디자인 검토와 기술 검토를 합성하고 부모 에이전트가 localhost:8443의 1280×720, 390×844 브라우저 화면을 확인했다. 코드는 수정하지 않았다.

## 판단
흰 바탕·RAOTA Red·5축 레이더는 결과 화면과 이어지는 좋은 기반이다. 기존 리포트 보기와 재발행 액션의 분리, 연출 건너뛰기, 타이머 정리, 전역 reduced-motion 대응도 유지할 장점이다. 개선의 중심은 화면 경계, 기다림의 길이, 문구의 일관성이다. 프로토타입 연출이라는 점을 감안해 실제 서비스 성능 문제와 구분한다.

## 우선순위
1. P1 화면 경계: :1018 fixed inset-0가 390px 앱 프레임 대신 1280px 브라우저 전체를 덮는 것을 DOM bounds와 화면으로 확인. 앱 콘텐츠 영역 기준으로 오버레이를 제한하고 결과 전환 시 같은 폭과 위치를 유지한다.
2. P1 시간/상태: :543–574는 실제 분석 호출 없이 5.2초 타이머를 재생한다. 4.2초에 100%, 그 뒤 1초 추가 대기한다. :577의 건너뛰기도 0.5초 후 완료한다. 프로토타입 첫 발행 연출은 약 2초를 시작안으로 검증하고 반복 갱신은 간소화한다. 실제 연동 시 요청 즉시 실행, 결과 준비 시 완료, 진행률을 측정할 수 없으면 퍼센트를 제거한다.
3. P1 수치 일관성: 마이페이지 42그릇→로딩 고정 43그릇(:1056)→결과 22그릇을 실제 화면에서 확인했다. 8,400개 매장·142개 태그·점수도 고정. 하나의 데모 데이터 또는 실제 데이터에서 일관되게 파생한다. 분석 전에 결과 점수를 확정해 보여주지 않는다.
4. P2 시각/문구 과밀: 연구소·실시간·STEP·제목·설명·레이더 점수·DNA/LIVE/%·바·배지·푸터가 경쟁한다. 1.1~1.2초마다 바뀌는 문장도 길다. 제목 한 줄, 기록 수 한 줄, 레이더 하나, 상태 한 줄로 줄인다. 식권/감열 헤드/영수증 설명(:470–498)은 현재 레이더와 맞지 않아 취향 리포트 용어로 통일한다.
5. P2 조작/접근성: 건너뛰기 실제 높이 26.5px. 44px 이상의 영역으로 확대한다. 로딩 상태/live region과 완료 후 포커스 전환이 없다. 덮인 뒤로가기/공유가 접근성 트리에 남아 있어 포커스 격리를 추가한다. reduced-motion은 이미 있으므로 유지한다.

## 권장 구성
상단: 취향 리포트 / 결과 보기(결과가 준비된 경우).
중앙: ‘나의 라멘 취향을 정리하고 있어요’ / ‘기록한 {N}그릇을 바탕으로 분석해요’.
시각물: 숫자를 제거한 레이더 축과 차오르는 붉은 면. 회전·깜박임·다수 배지 애니메이션은 줄인다.
하단: ‘기록 확인 → 취향 정리 → 리포트 완성’ 중 현재 상태 한 줄.
완료: 약 0.3~0.5초 완료 표시 후 결과 레이더로 연결하는 것을 제안한다. 제안 시간은 실측 성능이 아니다.
반복 갱신: 기존 리포트를 유지하며 작은 갱신 표시. 실서비스에서는 실패 시 기존 결과 유지 및 재시도.

## 휴리스틱 평가
소스와 브라우저 근거를 통한 정성 평가이며 사용자 테스트 점수가 아니다.
상태 표시 2/4, 현실 언어 2/4, 사용자 통제 2/4, 일관성 1/4, 오류 예방 1/4, 인지 용이성 3/4, 효율 2/4, 미니멀리즘 1/4, 오류 복구 0/4, 도움 1/4. 합계 15/40. 프로토타입의 미구현 오류 흐름도 포함하므로 실서비스 품질 등급으로 일반화하지 않는다.
이동 중 사용자: 작은 버튼과 읽기 어려운 메타 텍스트. 반복 사용자: 강제 연출 대기. 스크린리더 사용자: 로딩 상태/포커스 전달 부족.

## 검증 및 제한
웹 detector 결과 0건. 별도 모바일 검토에서 나온 색상 권고 2건은 이번 범위에서 제외. 기계 검사가 시간/수치/레이아웃 문제를 검출하지 못해 실제 화면과 코드 근거를 우선했다. CUA evaluate는 읽기 전용이므로 overlay script 주입은 미지원, 별도 live server는 시작하지 않았다. 실기기 네이티브 화면은 본 분석 대상이 아니다.

## 후속 결정
첫 발행의 레이더 연출을 유지할지, 식권 배출로 메타포를 바꿀지 선택할 수 있다. 현재 권장은 레이더 유지 및 간소화다. 가장 먼저 화면 경계와 데이터 수치를 맞춘 뒤 밀도·시간을 개선한다.
