# RAOTA 모바일 검수 가이드

## 자동 게이트

저장소 루트에서 다음 검사를 실행한다.

```sh
cd apps/mobile
npm run typecheck
npm test
npm run export:ios -- --output-dir /tmp/raota-mobile-ios
npx expo-doctor

cd ../..
./node_modules/.bin/tsc --noEmit -p packages/shared/tsconfig.json
./node_modules/.bin/vite build
```

단위·컴포넌트 테스트는 저장 스키마 복구, reducer와 영구 저장, 로그인·온보딩, 기록 폼, 알림 설정, 지도 권한 허용·거절, 검색·필터·정렬, 지도 클러스터, 취향 계산을 다룬다.

## iOS 기기 시나리오

iPhone 16 Pro를 기준으로 확인하고, 같은 빌드를 iPhone SE 크기에서 다시 확인한다. 각 시나리오가 끝난 뒤 앱을 강제 종료하고 다시 열어 변경 상태와 로컬 사진이 유지되는지 확인한다.

1. 비회원 홈 → 로그인 → 온보딩 → 홈
2. 홈 → 매장 상세 → 찜 → 기록 작성 → 완료 → 취향 리포트
3. 지도 위치 권한 허용 → 현재 위치 → 필터 → 마커 → 매장 상세
4. 지도 위치 권한 거절 → 기본 지역 → 설정 안내 → 목록 전환 → 매장 상세
5. 라운지 로그 좋아요 → 게시글 작성 → 상세 → 댓글 → 답글
6. 라멘속보 구독 → 알림 필터 → 읽음 → 전체 읽음 → 삭제 → 설정
7. 마이 → 프로필·선호 스타일 수정 → 로그아웃 → 재로그인
8. 사진 보관함·카메라 권한 거절 → 설정 안내 → 사진 없이 기록 저장

## 화면 품질 체크

- 상태 표시줄과 상·하단 안전 영역이 콘텐츠와 겹치지 않는다.
- 키보드가 입력 필드와 저장 버튼을 가리지 않는다.
- 모든 주요 터치 대상이 44pt 이상이며 VoiceOver에서 역할·상태·라벨을 읽는다.
- Dynamic Type을 키웠을 때 주요 문구와 동작이 잘리지 않는다.
- 원격 이미지 실패 상태가 레이아웃을 무너뜨리지 않는다.
- 모든 버튼이 이동, 상태 변경, 안내 중 하나로 응답한다.
